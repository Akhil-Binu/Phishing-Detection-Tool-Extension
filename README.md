# Phishing Detection Tool (AI + Cybersecurity)

An AI-powered cybersecurity solution designed to protect users against phishing attempts. It features a high-performance **FastAPI backend** running Machine Learning classifiers alongside lexical/domain reputation heuristics, and a **Chrome Extension (Manifest V3)** providing real-time browser protection.

---

## 🌟 Key Features

1.  **Real-Time Page Analysis**: Automatically checks the URL of the active browser tab on load and updates the extension badge (Green/Safe, Yellow/Suspicious, Red/Danger).
2.  **AI & Heuristic Scoring**: Combines Scikit-learn Machine Learning prediction models with rules-based security checks:
    *   *Typosquatting Check*: Tokenizes and checks Levenshtein edit distance against top global brands (Google, PayPal, Microsoft, Chase, etc.).
    *   *TLD Reputation*: Flags high-risk, low-cost top-level domain extensions (.xyz, .top, .su, etc.).
    *   *DNS Verification*: Queries live DNS for IP resolutions (A records) and mail server availability (MX records).
3.  **Email Phishing Analyzer**: Natural Language Processing (NLP) classifier powered by a TF-IDF text pipeline and Logistic Regression to flag credential harvesting, monetary alerts, and high-urgency keywords inside email bodies.
4.  **Client-Side Link Spoofing Detector**: Runs in the background of web pages to check if hyperlink text mentions a brand (e.g., "paypal") but routes the user to a completely different domain. Spoofed links are automatically highlighted with dashed red outlines and tooltip warnings.
5.  **Context Menu Scan**: Adds a right-click browser entry to let users right-click any link on a page and test it for phishing before clicking.

## 🚀 How to Run Locally

### 1. Start the FastAPI Backend
1.  Ensure you have Python 3.10+ installed.
2.  Open your terminal in the project root directory and install dependencies:
    ```bash
    pip install -r backend/requirements.txt
    ```
3.  Run the API server using Uvicorn:
    ```bash
    python -m uvicorn backend.main:app --reload
    ```
    *Note: On startup, the system checks if the ML models have been generated. If missing, it will automatically run the training pipeline, save the serialized models (`.joblib`), and spin up the API at `http://127.0.0.1:8000`.*

### 2. Install the Chrome Extension
1.  Open Google Chrome and navigate to `chrome://extensions/`.
2.  In the top-right corner, toggle **Developer mode** to **ON**.
3.  In the top-left corner, click **Load unpacked**.
4.  Navigate to your workspace directory and select the **`extension`** folder:
    `D:\Code\Phishing Detection Tool\extension`
5.  Pin the **Phishing Detector AI** extension to your toolbar. You are now fully protected!
